# OjiMate

集中しているとき、あなたの分身であるおじさんも隣の部屋で働いている。
サボってスマホを触れば、おじさんもスマホを触りはじめる。
表裏一体の相棒と一緒に、ボロアパートから庭付きの家を目指す集中アプリ。

## コンセプト

- **表裏一体** — おじさんはNPCではなく自分の状態がそのまま映る鏡。集中すればおじさんも机に向かい、サボればおじさんも一緒にサボる。
- **関係性の記憶** — 使い続けるほど、おじさんの反応が「今日も一緒に頑張ろう」から「昨日は遅くまで頑張ってたから今日は短めにしよう」のように変化していく。
- **成果の可視化** — 集中した時間がそのままお金になり、住む家が育っていく。やめた分もログに残る。

## このリポジトリ

`index.html` は上記コンセプトのスマホ画面デモ。Three.js でおじさんと部屋を描画し、タイマー・関係性レベル・家のグレードアップまでを単一ファイルで確認できる。

## 技術

- HTML / CSS / JavaScript + Three.js（依存はCDN読み込みのみ、単一ファイル）
- Cloudflare Workers（[worker/](worker/) — 任意設定。おじさんのセリフをAIエージェントに読ませたいときだけ使うプロキシ）

## おじさんをAIエージェントにする（任意）

初期状態ではセリフは全部ローカルの固定パターン（前回の作業時間や連続記録を見て組み立てる）。
